===============================================
CONTEXTO: TeleTony - Bot Telegram + n8n
===============================================

PROJETO: Bot Telegram que envia webhooks HTTP para o n8n (Docker)

-----------------------------------------------
ARQUITETURA
-----------------------------------------------

Servidor: 192.168.193.90 (Docker)

Containeres:
- telegrambot-bot-1   -> Rede: telegrambot_default
- n8n                 -> Porta 5678, Rede: telegrambot_default
- portainer           -> Porta 9000

Comunicação:
- Bot → n8n: http://n8n:5678/webhook/[nome]
- Containers na mesma rede Docker

-----------------------------------------------
ARQUIVOS DO PROJETO
-----------------------------------------------

bot.py               - Código principal do bot
docker-compose.yml   - Configuração do container
Dockerfile           - Imagem do container
requirements.txt    - Dependências Python

-----------------------------------------------
COMANDOS DO BOT
-----------------------------------------------

/start               - Mensagem de boas-vindas
/help                - Lista de comandos disponíveis
/ping                - Testar integração (webhook comandos)
/gasto [valor] [descrição] - Registrar gasto (webhook financas)

Exemplo:
/gasto 25.50 almoço

-----------------------------------------------
VARIÁVEIS DE AMBIENTE
-----------------------------------------------

No docker-compose.yml (hardcoded):

  bot:
    build: .
    restart: unless-stopped
    environment:
      BOT_TOKEN: ${BOT_TOKEN}
      N8N_URL_FINANCAS: "http://n8n:5678/webhook/financas"
      N8N_URL_COMANDOS: "http://n8n:5678/webhook/comandos"

Importante: O BOT_TOKEN precisa ser definido no Portainer Stack.
As URLs do n8n estão hardcoded e não precisam de variáveis.

-----------------------------------------------
WEBHOOKS N8N
-----------------------------------------------

Dois webhooks configurados:

1.Webhook Financas:
  URL: http://n8n:5678/webhook/financas
  Uso: /gasto [valor] [descrição]
  Body recebido: {"valor": 22, "descricao": "..."}

2.Webhook Comandos:
  URL: http://n8n:5678/webhook/comandos
  Uso: /ping (teste)

Importante: O workflow deve estar ATIVADO (toggle verde) para funcionar.

-----------------------------------------------
COMANDOS ÚTEIS (servidor)
-----------------------------------------------

Ver containers:
  docker ps -a

Ver redes:
  docker network ls

Ver containers em uma rede:
  docker network inspect telegrambot_default --format '{{range .Containers}}{{.Name}} {{end}}'

Ver logs do bot:
  docker logs telegrambot-bot-1 --tail 30

Restartar container:
  docker restart telegrambot-bot-1

Acessar container:
  docker exec -it telegrambot-bot-1 sh

Ver variáveis de ambiente:
  docker exec telegrambot-bot-1 sh -c 'echo $N8N_URL_FINANCAS'

Testar koneksi dari container:
  docker exec telegrambot-bot-1 sh -c 'wget -q -O- http://n8n:5678 --timeout=5'

N8N
-----------------------------------------------

2. Adicionar nó Webhook (definir path)
3. Adicionar nós intermediários (Set, Function, etc)

-----------------------------------------------
FLUXO DE DADOS
-----------------------------------------------

Telegram → Bot → Webhook n8n → Workflow → Planilha

Exemplo /gasto 25.50 almoço:
1. Usuário envia /gasto 25.50 almoço
2. Bot processa e envia POST para n8n:
   {"valor": 25.50, "descricao": "almoço"}
3. n8n recebe via Webhook
4. Workflow processa (Set, Function, etc)
5. Dados enviados para Google Sheets

-----------------------------------------------
PROBLEMAS COMUNS
-----------------------------------------------

1. Erro 404 no webhook:
   - Workflow não está ativado
   - Solução: Clicar no toggle verde no n8n

2. "UnsupportedProtocol" - URL sem http://:
   - Variável de ambiente vazia
   - Verificar se container foi redeployado

3. Conexão recusada:
   - Verificar se n8n está na mesma rede
   - docker network connect telegrambot_default n8n

4. localhost no lugar de n8n:
   - Containers não se comunicam por localhost
   - Usar nome do container: n8n

-----------------------------------------------
ATUALIZAR BOT
-----------------------------------------------

1. No PC local:
   - Editar bot.py
   - git add . && git commit -m "mensagem"
   - git push origin main

2. No servidor (192.168.193.90):
   - cd /caminho/para/teletony
   - git pull
   - docker build -t teletony:latest .
   - docker stop telegrambot-bot-1
   - docker rm telegrambot-bot-1
   - docker run -d --name telegrambot-bot-1 --network telegrambot_default -e BOT_TOKEN=... teletony:latest

Ou via Portainer:
   - Stack -> TeleTony -> Edit -> Recreate
